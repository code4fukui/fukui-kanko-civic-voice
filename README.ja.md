# fukui-kanko-civic-voice

このリポジトリには、福井県における観光が住民の幸福度に与える影響を調査したデータとその可視化が含まれています。データは定期的に収集され、観光振興策の検討に活用されています。

## デモ

- **[インタラクティブな調査結果](https://code4fukui.github.io/fukui-kanko-civic-voice/#kanko_202408.csv)**: 調査データのインタラクティブな円グラフと表形式のビューアです。ドロップダウンからさまざまな質問を選択できます。
- **[2画面比較](https://code4fukui.github.io/fukui-kanko-civic-voice/split.html)**: 異なるデータセットや質問を並べて比較できる2画面ビューです。
- **[3画面比較](https://code4fukui.github.io/fukui-kanko-civic-voice/split3.html)**: より詳細な比較分析を行うための3画面ビューです。

## 機能

- **インタラクティブなチャート生成**: 動的な円グラフと表で調査結果を可視化します。
- **データのフィルタリング**: ドロップダウンメニューから異なる質問を選択し、可視化をリアルタイムで更新します。
- **比較分析**: 2画面および3画面のHTMLページを使用してチャート生成ツールを複数読み込み、並べて比較できます。

## データ

このリポジトリには以下の調査結果ファイルが含まれています:

- [kanko_20240117-1.csv](kanko_20240117-1.csv) - 2024年1月の調査結果
- [kanko_202408.csv](kanko_202408.csv) - 2024年8月の調査結果
- [kanko_20250119.csv](kanko_20250119.csv) - 2025年1月の調査結果
- [kanko_202508.csv](kanko_202508.csv) - 2025年8月の調査結果
- [kanko_202601.csv](kanko_202601.csv) - 2026年1月の調査結果

データは[福井県観光DX推進マーケティングデータコンソーシアム](https://www.fukuishimbun.co.jp/category/fukui-kankodx)によって提供されており、[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)ライセンスの下で公開されています。
